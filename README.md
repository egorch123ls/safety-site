# Страница про “странные ссылки”

Мини‑сайт: объясняет, почему нельзя переходить по подозрительным ссылкам.

## Что внутри (файлы)

- **`index.html`**: разметка страницы + оверлей (экран “эффекта”).
- **`style.css`**: внешний вид, анимации, классы `is-open`, `shake`, `flash`.
- **`script.js`**: логика запуска/закрытия оверлея, тайминги эффекта, блокировка прокрутки на время эффекта.
