# Страница про “странные ссылки”

Мини‑сайт: объясняет, почему нельзя переходить по подозрительным ссылкам.

## Что внутри (файлы)

- **`index.html`**: разметка страницы + оверлей (экран “эффекта”).
- **`style.css`**: внешний вид, анимации, классы `is-open`, `shake`, `flash`.
- **`script.js`**: логика запуска/закрытия оверлея, тайминги эффекта, блокировка прокрутки на время эффекта.

## Запуск локально

Самый простой способ на macOS:

```bash
cd "/Users/egorcmorrou/Documents/скример"
python3 -m http.server 8000
```

Открой в браузере: `http://localhost:8000`

## Открыть с телефона по Wi‑Fi (локальная сеть)

1) Телефон и ноутбук должны быть в **одной Wi‑Fi сети**  
2) Запусти сервер так, чтобы он слушал на всех интерфейсах:

```bash
cd "/Users/egorcmorrou/Documents/скример"
python3 -m http.server 8000 --bind 0.0.0.0
```

3) Узнай IP-адрес ноутбука:

```bash
ipconfig getifaddr en0
```

4) На телефоне открой:

`http://<IP-НОУТБУКА>:8000`

## Публикация (GitHub Pages)

1) Создай репозиторий на GitHub (например `school-safety-site`)
2) Загрузи туда файлы `index.html`, `style.css`, `script.js`
3) В репозитории открой: **Settings → Pages**
4) В “Build and deployment” выбери:
   - Source: **Deploy from a branch**
   - Branch: **main** / **root**
5) Подожди 1–2 минуты — появится ссылка на публичный сайт.

## Настройки эффекта (быстро)

Настройки лежат в `script.js`:

- **`START_DELAY_MS`**: задержка перед стартом эффекта (используется для “планового” старта).
- **`EFFECT_MS`**: длительность эффекта (через сколько закрывается оверлей).

Сейчас автозапуск сделан через `setTimeout(..., 2000)` после загрузки DOM (см. `startWithDelay()`).

## Про прокрутку (важно)

Пока идёт эффект (оверлей открыт), прокрутка страницы **заблокирована**:

- колесо мыши и тач‑скролл (touchmove)
- клавиши: стрелки, пробел, PageUp/PageDown, Home/End

После завершения эффекта прокрутка возвращается и позиция страницы восстанавливается.

## Как отключить автозапуск (если нужно)

В `script.js` удали/закомментируй блок с `startWithDelay()` и вызовами при `DOMContentLoaded`, и запускай вручную (например, по кнопке).

## Частые проблемы

- **Эффект “не стартует”**: если открываешь `index.html` как файл (через `file://`), некоторые браузеры могут вести себя иначе. Надёжнее запускать через локальный сервер (`python3 -m http.server`).
- **На телефоне не открывается**: проверь, что устройства в одной Wi‑Fi сети и что сервер запущен с `--bind 0.0.0.0`. Также может мешать firewall.
